# Recortes de datos para tests

Recorte de la Serra de Tramuntana (lat 39,73–39,89, lon 2,62–2,96) de la release `datos-2026.10.31-6` de
`rally-copilot-data`: `vias-serra.tsv.gz` (formato `#vias-mallorca v1`, vías que tocan el recuadro) y
`vias-notas-serra.tsv.gz` (`#vias-notas v1`, líneas V/P de esas vías y nodos N del recuadro). Cubre la Ma-2141 y la
Ma-10 Sóller–Lluc de `docs/rutas/`. Datos © OpenStreetMap contributors (ODbL 1.0); alturas MDT05 CC BY 4.0 scne.es.
